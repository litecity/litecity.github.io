# LiteCity 轻量造景沙盘

给城市建造游戏造景玩家用的轻量规划工具：开游戏之前，先在浏览器里把地形、水系和路网推演一遍。

在线使用：<https://litecity.github.io/>

也可以直接下载 `index.html`，双击在本地浏览器里打开，不需要网络，存档保存在浏览器本地。

> 非官方工具，与任何游戏的开发商、发行商无关。

## 功能

- **左右同步**：左边平面图，右边 3D 实景，共用一份数据。
- **道路**：直线或自由曲线（先定方向再定终点），同一高度相交处自动切开并生成路口；自动摆路灯。
- **车道**：每条路是一串车道，逐条设为前行、逆行、应急车道、封闭或分隔带；自带街道、大道、单向快速路、匝道等路型。
- **立交与匝道**：把一条路打断，再从某条车道处“切成两条路”，车道原位不动；把其中一条的远端拖走就是匝道。车道首尾对齐处车直接驶过，不需要路口，一条路也不必只连一条路。
- **人流与车流模拟（可开关）**：每栋建筑可设流入、流出人数随时间的曲线或常量。出门的人优先去有流入缺口的建筑，没有缺口就离开城市；缺口没人填就从城外来人。短途步行，其余开车。车会变道（必须变和值得变两种），左转让对向，次路让主路；拥堵热力图按车速上色。
- **路口工具（类似 TM:PE）**：点一个路口，选自动红绿灯、无信号按让行标志，或自定义定时红绿灯：一步一步编，每步每个进口的左转、直行、右转各自放行或禁行。
- **桥和隧道**：“路面”选桥或隧道，路在两端之间架空或穿山。桥有桥墩和栏杆，隧道内部有路面、内壁、灯带，隧道里也能做路口。
- **修路自动平整地形**：贴地的路会把路面范围内的地形整平，两侧放坡接回原地面。
- **地形**：18×18 km，每格约 17.6 m；黑白高度图导入、随机山脉（参数可调）、按海拔抹平的笔刷。
- **水**：海平面、洼地积水成湖、沿坡河流、人工水点（指定水面海拔）、像修路一样画的沟渠；水面有波光。
- **光影（可关）**：太阳阴影、会移动的云和云影；陡坡自动露出分层的岩石。
- **日月与昼夜**：太阳和月亮按本地时间出现在天上，月亮带月相；入夜后有星星，窗户和路灯亮起。也可以关掉“本地时间”手动拖时辰。
- **贴地仰视**：把镜头压到贴近地面后继续上抬，就变成站在地上抬头看天。
- **面板可收起**：平面图和实景各有“放大”按钮，收起另一侧占满；实景占满时鼠标移出画框，镜头继续往那边走。
- **树刷子**：在山上刷树。只存一张密度图，镜头附近才生成一棵棵树。
- **资产**：每件资产是一份矢量配方（若干体块的位置、尺寸、颜色），可在建造车间里手动搭建或随机生成。
- **轻量**：零贴图，天空、云、草地、水面、窗格全部由着色器现算；发布出来是单个 HTML 文件，运行时无依赖。

## 已知限制

- “AI 生成资产”按钮只在 Claude 的页面环境里可用，在这里会显示为不可用；其余功能不受影响。
- 有地形时内存约 12 MB、显存约 22 MB；平地时为 0。开“光影”再加约 8 MB 显存。
- “云动”或“波光动画”打开时每秒约重绘 11 帧；都关掉后只在画面变化时重绘。
- 镜头不能钻进隧道，只能从洞口往里看，或在选“隧道”时透过半透明的地形看。
- 最多同时为约 48 段洞口路段挖开地形，隧道很多时后画的洞口可能被山体挡住。
- 模拟里车过路口是瞬间通过的，不占用路口内部；没有任何下游的行车方向被当作城市出入口（断头路也算）。
- 字体从 Google Fonts 加载，加载不到时退回系统字体。

## 开发

源码在 `src/`，根目录的 `index.html` 是构建产物（一并提交，GitHub Pages 直接用它）。

```
src/style.css      样式
src/body.html      页面结构
src/js/*.js        脚本模块，按 build.mjs 里 MODULES 的顺序拼进同一个作用域
build.mjs          构建脚本，只需要 Node，没有任何依赖
```

```
node build.mjs           # 生成 index.html，同时做语法检查
node build.mjs --check   # 检查 index.html 是否和源码一致
```

各模块大致分工：`state` 城市数据与存档，`lanes` 车道模型与切分，`roads` 道路几何与路口，`inspect` 属性面板，`sim` 人流车流模拟，`tools` 两个视图共用的工具逻辑，`mesh` 网格与道路建模，`terrain` / `canals` / `trees` 地形、水文、沟渠和树，`sky` 日月与天色，`shaders` 着色器，`render3d` 实景，`plan2d` 平面图，`input` 指针手势，`workshop` 建造车间。

调试时可以在浏览器控制台用 `window.LiteCity`（城市状态、镜头、重绘、天空状态）。
