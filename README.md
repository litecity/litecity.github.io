# LiteCity 轻量造景沙盘

给城市建造游戏造景玩家用的轻量规划工具：开游戏之前，先在浏览器里把地形、水系和路网推演一遍。

在线使用：<https://litecity.github.io/>

也可以直接下载 `index.html`，双击在本地浏览器里打开，不需要网络，存档保存在浏览器本地。

> 非官方工具，与任何游戏的开发商、发行商无关。

## 功能

- **左右同步**：左边平面图，右边 3D 实景，共用一份数据。
- **道路**：直线或自由曲线（先定方向再定终点），相交处自动切开并生成路口。
- **地形**：18×18 km；黑白高度图导入、随机山脉（参数可调）、按海拔抹平的笔刷。
- **水**：海平面、洼地积水成湖、沿坡河流、人工水点（指定水面海拔）、像修路一样画的沟渠。
- **资产**：每件资产是一份矢量配方（若干体块的位置、尺寸、颜色），可在建造车间里手动搭建或随机生成。
- **轻量**：零贴图，天空、云、草地、水面、窗格全部由着色器现算；单个 HTML 文件，无依赖、无构建步骤。

## 已知限制

- “AI 生成资产”按钮只在 Claude 的页面环境里可用，在这里会显示为不可用；其余功能不受影响。
- 地形一格约 35 m，小于一格的起伏刻不出来。
- 道路相交都是平面路口，没有立交和桥。
- 字体从 Google Fonts 加载，加载不到时退回系统字体。
